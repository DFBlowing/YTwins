# 08: 排程 —— 事项落到时间上

**What to build:** **事项**被自动落到时间上，用户不用自己填时间。页面上能看到即将到期的事项列表，
打开页面就知道该做什么；没有解析出时间的事项留在「待安排」，而不是被丢掉。

**Blocked by:** 02（接住的结构 —— 自动分出事项与留档）

**Status:** ready-for-agent

- [ ] 含时间信息的事项被自动落到具体时间上，用户无需手工填写。
- [ ] 没解析出时间的事项保留为「待安排」，不被静默丢弃。
- [ ] 页面按时间列出即将到期的事项，以及单独的待安排列表。
- [ ] 事项的状态可被推进（例如从待办变为已办），且该状态在刷新后仍然保留。
- [ ] 排程不引入完整日历 UI，也不做冲突检测。
- [ ] demo 阶段不做系统级推送与提醒可靠性保证。
