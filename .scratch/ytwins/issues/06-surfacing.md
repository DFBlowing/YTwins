# 06: 浮现 —— 情绪投递时的那一条

**What to build:** 当用户**情绪投递**时（而不是任何时候），系统尝试**浮现**一条**小结论**：
默认不主动推送，每轮最多一条，同一主题 **7 天内只浮一次**，且措辞一律是不确定语气（「你似乎…」「你最近…」）。
措辞的强弱由**可解释的数值**决定（支撑词条数量、平均链接强度、时间跨度），而不是让模型当场「感觉」
一个语气 —— 这样日后能回答「你当时为什么这么说」。支撑不足时宁可不浮，或明说「我不太确定」。

**Blocked by:** 05（阈值汇集 —— 第一条小结论、画像与结论链）

**Status:** ready-for-agent

- [ ] 只有**情绪投递**或用户主动询问才尝试浮现；其余投递不触发。
- [ ] 每轮最多浮出一条；零条是正常结果（冷却中、或支撑不足），不是错误。
- [ ] 同一主题 **7 天内不重复浮现**。
- [ ] **主题**的工程定义是「支撑该结论的词条集合的语义重叠」，重叠超过一个由可配置常量承载的内部比例即视为同一主题。
- [ ] 浮现内容一律为不确定语气，措辞强弱由支撑词条数量、平均链接强度、时间跨度这些可解释数值映射得出，不由模型自由选择语气。
- [ ] 不确定语气只作用于**答案**与**浮现**，不改写普通**回应**。
- [ ] 支撑不足时不浮现，或明确说「我不太确定」，不靠断言烧掉信任。
- [ ] 每次浮现留下记录，使冷却判定在重启后依然成立。
