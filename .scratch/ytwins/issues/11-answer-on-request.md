# 11: 主动询问 —— 一次观察（答案）

**What to build:** 用户直接问「你觉得我最近怎么样」时，拿到一次观察：它把多条**小结论**汇集而成一句话，
只可能出自用户自己的数据，不给出放之四海皆准的废话；措辞是不确定语气，并说明背后的支撑；
支撑不足时宁可不说，或明说「我不太确定」。

**Blocked by:** 06（浮现 —— 情绪投递时的那一条）

**Status:** ready-for-agent

- [ ] 用户主动询问时返回一条**答案**，它由多条**小结论**汇集而成，而不是单条结论的复述。
- [ ] 答案只可能脱胎于用户自己的数据；测试用「换一套数据就答不出来」的方式断言这一点。
- [ ] 答案一律为不确定语气，措辞强弱由可解释数值映射得出（与**浮现**共用同一套映射）。
- [ ] 答案显示它由哪些**小结论**／**词条**支撑。
- [ ] 支撑不足时返回「我不太确定」或明确不给出答案，不编造。
- [ ] 主动询问与**浮现**共用同一套冷却与条数上限，两者不会在同一轮里各出一条。
