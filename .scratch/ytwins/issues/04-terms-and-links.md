# 04: 词条与链接 —— 把碎片连起来

**What to build:** 每次投递抽出**词条**，并保留用户自己的说法（是「想学吉他」，不是「音乐兴趣」）。
**词条**之间自动长出**链接**，两类并存：**同一次投递里共同出现**的零模型硬边，以及**语义相近**的
相似度边（预训练 embedding 的余弦相似度 + 阈值，三段式处理：高分直接连、低分不连、**灰区**才调
`judgeLink`，或先漏连）。每条链接带可比的强度与连接理由，对用户可见（或至少可读）。

**Blocked by:** 02（接住的结构 —— 自动分出事项与留档）

**Status:** ready-for-agent

- [ ] 抽出的**词条**保留用户自己的说法，而不是被改写成上位概念。
- [ ] 同一次投递里共同出现的词条之间长出硬边链接，全程不调用任何模型。
- [ ] 语义相近的链接由词条向量余弦相似度决定，按三段式处理：高分连接、低分不连、灰区调 `judgeLink`。
- [ ] 灰区策略（调 `judgeLink` 或暂时漏连）由一个可配置常量承载，便于日后改口径。
- [ ] 每条链接记录可比的强度与「为什么连上」的理由。
- [ ] 链接的相似度阈值与灰区边界由可配置常量承载，不散落在实现里。
- [ ] 假 provider 返回确定性向量与确定性 `judgeLink` 判定，因此链接结果在测试里完全可断言。
