# 13: 三幕 demo —— 预置数据与可重复

**What to build:** 三个动作在预置数据上稳定、可重复地跑出来：① **丢** —— 丢一段含老师讲的评分标准 +
一句情绪的杂乱输入，不选类型、不填时间，自动分出**事项**与**留档**；② **问** —— 以「几天后」的视角问
「期末怎么算分」，准确答出并指出源自哪次**投递**；③ **浮** —— 再丢一句情绪化输入，浮出一条**不确定语气**
的**小结论**，由**预置的足够词条**支撑。页面同时明确告诉用户哪部分数据会离开这台机器。

**Blocked by:** 06（浮现 —— 情绪投递时的那一条）、07（追溯 —— 问一件旧事，答得准并指出出处）、
12（真实 provider —— 云端 LLM + 本地 embedding + 可切换）

**Status:** ready-for-agent

- [ ] 第一幕：一段含评分标准与一句情绪的杂乱输入，不选类型、不填时间，自动分出**事项**与**留档**。
- [ ] 第二幕：以「几天后」的视角问「期末怎么算分」，得到准确回答并看到它源自哪一次**投递**。
- [ ] 第三幕：再丢一句情绪化输入，浮出一条有足够**预置词条**支撑的**不确定语气**小结论。
- [ ] 三幕共用同一套预置数据，且该套数据与领域测试使用的预置数据是同一份。
- [ ] 三幕可以连续重跑而结果不变（同一套预置数据、同一条链路，不靠运气）。
- [ ] 页面明确告知哪部分数据会离开这台机器（demo 阶段：送去云端 LLM 的原文），embedding 留在本地。
- [ ] 整个 demo 不需要账号、不需要联网完成注册；不做系统级推送与提醒。
- [ ] 三幕的演示脚本以中文写进仓库，供日后复现。
